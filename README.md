# Portfolio Crew

프로젝트 기록에서 본인의 기술적 판단과 검증 결과를 찾아 개발자 포트폴리오로 만드는 Codex 스킬입니다. 여러 에이전트가 기획, 근거 편집, 디자인·모션, 구현, QA를 나눠 맡고 메인 에이전트가 결과를 통합합니다.

## 실행 흐름

- **신규 제작**은 실제 콘텐츠가 들어간 첫 화면, 핵심 전환 한 장면, 대표 프로젝트 상세 한 편을 브라우저에서 먼저 연결합니다. 모바일·데스크톱 화면과 조작 녹화를 검토한 뒤 나머지 사례에 적용합니다.
- **기존 사이트 수정**은 기준 버전과 수정 범위를 먼저 확인합니다. 상세 문구를 바꾸거나 AI 활용 탭을 추가할 때도 갤러리, 영상, 개발 기록, 뒤로가기 등 기존 흐름을 검수합니다.
- **채용용 사례**는 개인 역할, 해결한 문제, 기술적 판단, 검증 결과를 중심으로 구성합니다. 제출 요건에 따라 공개 사이트나 PDF를 준비합니다.

## 설치

이 저장소의 [portfolio-crew](./portfolio-crew) 폴더를 개인 Codex 스킬 디렉터리인 `~/.codex/skills/`에 복사합니다. 특정 저장소에서 사용할 때는 그 저장소의 `.agents/skills/`에 복사합니다. Codex에서 `$portfolio-crew`로 호출합니다.

### 사용 예시

> $portfolio-crew로 이 저장소의 프로젝트 기록을 바탕으로 백엔드 지원용 포트폴리오를 만들어 주세요. 대표 프로젝트 상세 한 편과 첫 화면을 연결하고 스크롤 전환을 브라우저에서 검수해 주세요. 배포 전 로컬 검수까지 진행해 주세요.

> $portfolio-crew로 기존 포트폴리오의 프로젝트 상세 문구를 다듬고 사이드바에 AI 활용 탭을 추가해 주세요. 현재 공개 버전을 기준으로 홈과 기존 갤러리·동영상·개발 기록이 유지되는지 확인해 주세요.

| 도구 | 용도 | 요구 사항 |
| --- | --- | --- |
