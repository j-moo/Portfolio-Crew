# 제작과 인계

## 자료에서 독자 동선까지

1. 작업 기록, 코드·PR, 시연, 테스트 등 사용자가 지목한 자료에서 프로젝트별 근거를 찾는다. 출처 위치, 확인할 수 있는 사실, 팀과 개인의 담당 범위, 공개 가능 여부를 작업 메모에 적는다. 자료가 방대하면 기록 목록을 만든 뒤 대표 사례의 결정과 결과부터 교차 확인한다.
2. 참고 사례는 타이포그래피, 여백, 그리드, 이미지, 전환뿐 아니라 첫 화면에서 지원자를 파악하는 데 필요한 정보와 상세 근거까지 살펴본다. 관찰한 특징을 적용 결정과 확인 방법으로 연결한다. 여러 레퍼런스가 충돌하면 사용자가 선택한 화면이나 요소를 기준으로 삼는다.
3. 대표 사례는 지원 직무나 심사 기준과의 관련성, 개인 판단의 구체성, 검증 자료의 유무로 고른다. 직무 우선순위가 없다면 서로 다른 강점을 발견할 수 있는 진입점을 마련한다. 첫 화면에서 대표작과 역할을 확인하고 상세에서 판단과 근거를 찾는 동선을 짧게 만든다.

## 역할별 인계

| 담당 | PM에게 전달할 것 | 확인할 것 |
| --- | --- | --- |
| 웹 기획자 | 사이트맵, 대표 사례로 진입하는 흐름, 화면별 목적과 필요한 콘텐츠 | 독자가 어디서 역할을 파악하고 어떤 동작으로 근거를 여는지 설명할 수 있다. |
| 콘텐츠 에디터 | 대표 사례 원고, 출처가 붙은 주장과 수치, 사용할 이미지와 미해결 질문 | 팀 결과와 개인 기여가 읽는 순서에 드러나고, 공개 가능한 근거가 주장 옆에 있다. |
| UI·모션 설계 | 실제 문구와 서비스 화면을 넣은 기준 화면, 타이포·간격·그리드, 전환 명세 | 긴 제목과 모바일에서도 읽을 수 있다. 전환 전후 상태, 트리거, 지속 시간, 이징, 취소·역방향 동작, 축소 모션 조건이 분명하다. |
| 프런트엔드 구현 | 실행 가능한 대표 흐름, 데스크톱·모바일 캡처, 실제 입력으로 녹화한 핵심 전환 | 지정된 진입점과 이동 이후 상태를 확인할 수 있다. 레이아웃과 전환 변경은 설계와 맞춘다. |
| 독립 QA | 재현 단계, 기대·실제 결과, 캡처나 영상, 검증한 화면·브라우저 | 정상 진입, 역방향 이동, 모바일과 축소 모션을 직접 실행한다. 부분 수정에서는 기존 기능도 확인한다. |

PM은 기획과 원고가 같은 사례를 같은 순서로 보여 주는지 먼저 확인한다. 첫 화면·전환·대표 상세가 연결된 상태에서 시안과 원고를 함께 검토한다. 수정이 필요하면 정확한 화면, 관찰한 동작, 기대한 결과를 남겨 해당 담당자가 고칠 수 있게 한다.

## 프로젝트 상세 원고

- 첫 단락은 **내 역할 → 어려웠던 문제 → 내 판단과 작업 → 확인된 결과**로 연결한다. 무엇을 만들었는지 이해할 서비스 소개, 기술 선택, 주요 기능 개발, 트러블슈팅을 이어 배치한다. 요구된 구성과 기존 사이트의 읽기 흐름을 따른다.
- 대표 이미지는 사용 가능한 실제 서비스 화면이나 시연에서 고른다. 글에 언급한 동작을 화면이나 캡션에서 확인할 수 있도록 연결한다. 상세한 일지·도표·갤러리는 필요한 곳에 연결하거나 기존 펼침 구조에 둔다.
- 실험 결과는 비교 대상, 환경, 표본이나 관찰 범위를 함께 쓴다. 확인되지 않은 역할·성과는 작업 메모에 남기고, 수치가 없어도 재현 가능한 검증이 있으면 확인한 동작을 설명한다. 배포 성공, 시험 통과, 사용자 성과는 근거에 맞는 표현을 각각 쓴다.
- AI 활용을 요구하는 지원이라면 어떤 일을 AI에 맡겼고 본인이 어떤 조건을 정했는지, 무엇을 검증하거나 바로잡았는지 적는다. 별도 탭을 요청받으면 상세의 구조와 기존 동선을 유지하며 탭을 추가한다.
- 파일 제출이 요청되면 제한에 맞춰 사례를 고르고 PDF의 줄바꿈, 가독성, 링크를 확인한다. 링크로 제출할 사이트와 첨부 자료는 로그아웃 상태에서 열어 본다.

가상 예시. “팀은 도서 예약 서비스를 만들었습니다. 저는 예약 상태 조회를 담당하면서 요청 지연 뒤에도 예약 결과가 중복 표시되는 문제를 발견했습니다. 오래된 응답을 무시하도록 화면의 상태 갱신 조건을 바꿨고, 응답 순서를 뒤집은 두 테스트 케이스에서 최신 결과가 유지되는 것을 확인했습니다.” 원고 옆에는 해당 테스트나 동작을 볼 수 있는 자료를 붙인다.
